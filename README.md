Telegram Dictionary Bot

This project is a Telegram bot developed in Python to support learning foreign language vocabulary (German–Russian). The bot allows users to create and manage their own dictionary and practice words through interactive lessons.

Features:
- Add, update, and delete words with translations
- Assign words to topics (e.g. school, work, food, travel)
- Store grammatical information (word type, gender for nouns)
- Start learning sessions by topic or based on previously incorrect answers
- Practice translations in both directions (German → Russian / Russian → German)
- Track user results and repeat difficult words

Technical Details
- Programming language: Python
- Telegram framework: python-telegram-bot
- Database: relational database (PostgreSQL)
- Data modeling using object-oriented programming (OOP)
- JSON used for importing and managing word data
- Step-by-step wizard logic for user interaction

Purpose
This project was created as a learning project to deepen practical skills in Python, SQL, database design, and object-oriented programming, as well as to gain experience in developing structured, real-world applications.
